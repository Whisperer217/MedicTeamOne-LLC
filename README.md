# Medic Team One, LLC website

Source repository for [medicteamone.com](https://medicteamone.com/), a static GitHub Pages site for Medic Team One's civilian trauma-preparedness training in Montgomery County, Texas.

## Provenance and source of truth

- The current HTML pages and their Git history are the source of truth for published website content.
- Jacob Ross's first-person testimony and authored material remain attributed to Jacob.
- Military service claims, third-party credentials, partner assets, medical guidance, testimonials, and legal statements should not be added or expanded without source evidence and the relevant person's or organization's authorization.
- `Civilian Responder One` is a Medic Team One preparedness program and completion certificate. It is not a state or nationally recognized EMS credential.
- Partner-owned equipment shown on `resources.html` is identified as external to Medic Team One.

The previous README described older prices, dates, course lengths, testimonials, federal services, patents, credentials, and outcome statistics that were not consistent with the current site. Those claims were removed from this repository overview rather than silently carried into the website.

## Site structure

- `index.html` — overview and training inquiry form
- `training.html` — training formats, pricing, scheduling model, and core curriculum
- `about.html` — Jacob Ross biography and provenance-separated credentials
- `doctrine.html` — curriculum lineage and readiness framework
- `resources.html` — partner-owned expanded training capabilities
- `book.html` — *Blood, Dirt & Duct Tape: A Combat Medic's Legacy*
- `privacy.html`, `terms.html`, `waiver.html` — legal and privacy documents
- `assets/styles.css` — shared visual system
- `assets/main.js` — navigation and progressive reveal behavior

## Publishing

The site is served by GitHub Pages using the custom domain recorded in `CNAME`.

Before publishing material changes:

1. Review factual claims against their originating evidence.
2. Confirm first-person wording with its author.
3. Obtain professional review for medical or legal claims where appropriate.
4. Test keyboard navigation and desktop/mobile layouts.
5. Verify links, metadata, structured data, `robots.txt`, and `sitemap.xml`.
